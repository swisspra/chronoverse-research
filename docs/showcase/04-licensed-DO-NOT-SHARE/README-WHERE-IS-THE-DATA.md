# ข้อมูลกับสคริปต์ย้ายออกจากที่นี่แล้ว

โฟลเดอร์นี้เคยเก็บข้อมูลอนุพันธ์ของคลังลิขสิทธิ์ (L1) ซึ่ง **ห้ามอยู่ใน repo สาธารณะ**

| ของเดิม | ตอนนี้อยู่ที่ |
| --- | --- |
| `data/` — คำถาม 598 ข้อ, ตารางราคาที่แกะมา, คำตอบทุก arm, log การรัน | Azure Blob `derived-licensed/showcase/data/` |
| `scripts/*.py` | ซ้ำกับฉบับที่ใช้จริงใน `benchmarks/asof-pilot/` ของ repo นี้ · สำเนาเดิมอยู่ Blob `derived-licensed/showcase/scripts-copy/` |

`scripts/LINEAGE.md` ยังอยู่ เพราะเป็นคำอธิบายว่าสคริปต์รุ่นไหนให้ผลชุดไหน ไม่มีเนื้อลิขสิทธิ์
