# HTML สถาปัตยกรรมอยู่ใน repo ภายใน

ไฟล์ `chronoverse-*.html` ในโฟลเดอร์นี้เป็นเอกสารสถาปัตยกรรมและเอกสารเชิงธุรกิจภายใน
`.gitignore` ของ repo สาธารณะกันมันไว้ตั้งแต่ต้น (`chronoverse-*.html`) จึงย้ายไปเก็บที่

```
repo-private/docs/architecture/showcase-05/
```

ชุดโชว์ที่เหลือในโฟลเดอร์นี้ยังครบ — ผลวัด โปรโตคอล ไทม์ไลน์ และสรุปเทียบคู่แข่ง
