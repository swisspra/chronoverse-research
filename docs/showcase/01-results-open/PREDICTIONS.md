## Fixed protocol

Production weights remain 0.35 lexical, 0.50 vector, 0.15 one-hop graph; the semantic threshold remains 0.28. Cross-domain comparisons use title plus newline plus passage, normalized vectors, exact search, top-100 RRF pools, RRF k=60, linear nDCG gains, self-document exclusion and the previous bootstrap seed (recorded by the runner). New delivery ranking uses the same production ranker unless an arm explicitly says otherwise. Gold labels never reach retrieval or index fitting.

Report raw paired 95% bootstrap intervals, two-sided paired permutation p-values, Holm-adjusted p-values, and separately labelled Bonferroni simultaneous bootstrap intervals within a named comparison family. Reuse paired query samples; related synthetic queries are clustered by entity/scenario. At least 10,000 resamples and a fixed seed 20260912 for new experiments. Cross-domain reference is MiniLM hybrid at the same context length. Include the three direct FiQA hybrid-minus-BGE comparisons/configurations in an explicitly separate confirmatory family when applicable; do not quietly omit the claim's own contrast.

The synthetic TEST target is 500 unique recipient/query/scope combinations with a separate DEV set. Retain the original 50 in a labelled compatibility set, scored separately and never used for DEV selection. Split new DEV and TEST by disjoint entity and scenario-family variants; report parent mechanisms shared across splits explicitly. Family variants are not independent mechanisms. Use at least 5,000 assertions, 300 lifecycle events and 10,000 receipts across 8–12 recipients. Event-only questions are scored on notice retrieval rather than forced abstention. Near-duplicate versions have identical retrieval text, differing only in validity metadata. Distractors are adjacent in topic and time.

Answer experiments use the same versioned prompt and answerer in all arms, temperature zero where supported, three independent repeats, and bounded outputs. Prompt carries recipient_id, valid_at, known_at and received_by for every arm. A/C/D/E have identical context token limits; B's larger context is separately reported and bounded. A pilot has 50 TEST questions; a full claimed answer comparison has at least 300, targeting 500. A fixed sample count does not guarantee ±0.03 precision. An underpowered or unrun arm remains labelled as such.

Citation-based leakage and staleness are exact only with complete IDs; uncited semantic leakage requires a separate blinded content adjudication. Report that distinction. A legitimately held older claim is not automatically stale solely because an unreceived global correction exists. Gold equivalence, abstention and event-only rules are fixed before dispatch. No spend occurs without an authorized provider, configured credential and a conservative pre-dispatch reservation below the user's budget.
