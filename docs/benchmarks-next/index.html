Finding: preserving eligible evidence does not solve sufficiency. The ungated methods all return context in cases that require abstention. The item view also adds explicit passage/notice retrieval, so its gain combines capability coverage with temporal handling.

This is a presence-rule diagnostic against external labels, not a Chronoverse retrieval ranking, generated-answer score, or official FANToM leaderboard submission. 05 / LongMemEval: a timestamp filter can hurt

500 public questions processed locally; support-session recall uses 470 answerable questions. Retrieving a chunk from the right session does not establish that the chunk contains the answer.

Local diagnosticSession recall@5Session recall@10

The minute-level cutoff removes 70 officially expected support sessions across 41 questions. All are later times on the same calendar day. These timestamps are not validated source-recording or receipt clocks; this result evaluates our simple cutoff policy and does not establish a Chronoverse or Graphiti result.

All 30 abstention questions receive nonempty contexts in both arms. No answer model or provider API was used.
