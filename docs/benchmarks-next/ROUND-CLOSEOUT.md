## Decision gates still open

1. **Full500 answers:** completed input preparation is not a completed 7,500-request comparison. Preserve the pilot's 50-question overlap and report the 450 nonpilot questions separately in a future full run; a changed completion cap requires separate attribution.
2. **Answer-level kill criteria:** long-context B versus E and post-filter D versus E remain untested in a completed answer comparison. Do not claim these criteria survived. The strong-BM25 FiQA criterion was tested: the hybrid loss remains, with a smaller magnitude than the weak-baseline result.
3. **Clock answers:** the four-mode inputs/statistics code do not establish an answer-level delivery-clock effect.
4. **Native public head-to-head:** actual Graphiti/Chronoverse evaluation on FANToM and LongMemEval, faithful public metrics, matched answerers and measured ingest/query costs remain open. A native smoke and public diagnostic are not substitutes.
5. **Semantic grading and paper:** blinded equivalence/error adjudication is pending. The [paper study brief](../paper/STUDY-BRIEF.md) is a plan, not a completed paper, novelty finding, submission-ready package or authorization to submit.

## Interpretation and documentation findings

The strongest completed synthetic result concerns **filter order**: ordinary SQL and Delivery have identical top-five IDs, scores and candidate projections on all 658 measured queries. It supports applying recipient receipts before destructive lifecycle projection; it does not establish unique graph superiority. Item-view gains add a result capability and must stay separately labeled. Public static ranking gains, public presence/session diagnostics and synthetic lifecycle results answer different questions.

All new artifact verification discussed here was carried out by additional implementations or agents **within the same project/team**. “Independently recomputed” can describe separation of scoring code; it must not imply unaffiliated external replication. The supplied external review's claims are attributed with the authentication limits stated in [EXTERNAL-REVIEW.md](../EXTERNAL-REVIEW.md).

One existing navigation issue was found without editing its owner’s page: `docs/benchmarks-next/README.md` links `REFERENCE-DISAGREEMENTS.md` relative to that directory, while the committed file is [benchmarks/REFERENCE-DISAGREEMENTS.md](../../benchmarks/REFERENCE-DISAGREEMENTS.md). The closeout's links use the real location. The wording and historical-archive exceptions in WI-03/04 prevent a literal claim that every proposed editorial acceptance condition is finished.

This audit was limited to committed artifacts, source/protocol inspection, repository state, exact fixture counts and link checks. It did not rerun expensive benchmarks, inspect partial pilot scores, change a baseline or execute the next study. The round remains open until the outstanding outcome and review gates above are resolved or explicitly descoped.
